Summary

The default @page rule makes every page A4 portrait. The next section is wrapped in an element carrying page: wide, which switches to the named page @page wide { size: A4 landscape } — the renderer starts a new page with that size and orientation, then comes back to the default afterwards.

Use this for wide tables, charts or plans in the middle of an otherwise portrait document.
